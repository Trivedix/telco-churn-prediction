# 📡 ChurnGuard AI — Telecom Customer Churn Prediction System

Machine Learning based system jo telecom customers ke churn hone ka risk predict karta hai, ek dynamic Flask web app ke through.

## 📁 Project Structure
```
churn_project/
├── data/                   # Raw + cleaned CSV yahan aayega
├── models/                 # Trained model, encoders, scaler (auto-generated)
├── static/
│   ├── css/style.css
│   ├── js/main.js
│   └── plots/              # EDA plots (auto-generated by eda.py)
├── templates/
│   ├── index.html          # Prediction form page
│   └── dashboard.html      # Model performance dashboard
├── read_data.py            # Step 1: Load raw data
├── clean.py                # Step 2: Clean + encode + scale data
├── eda.py                  # Step 3 (optional): Generate EDA plots
├── train.py                # Step 4: Train & save best ML model
├── app.py                  # Step 5: Run the Flask web app
└── requirements.txt
```

## 🚀 Setup Steps

### 1. Dataset daalo
[Telco Customer Churn dataset](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) download karke
`data/telecom_churn.csv` naam se save karo.

> Agar tumhara dataset ka structure/column names different hain, `read_data.py`, `clean.py`, aur `app.py` ke andar `FORM_FIELDS` / column names update kar dena.

### 2. Dependencies install karo
```bash
pip install -r requirements.txt
```

### 3. Pipeline chalao (order important hai)
```bash
python read_data.py     # sirf sanity check ke liye (optional)
python clean.py         # data clean + encode + scale, saves to data/cleaned_churn.csv
python eda.py           # optional: generates plots in static/plots/
python train.py         # trains 3 models, saves best one to models/churn_model.pkl
```

### 4. Web app run karo
```bash
python app.py
```
Browser mein kholo: **http://127.0.0.1:5000**

- `/` → Dynamic prediction form (customer details bharo, real-time churn risk milega with animated gauge)
- `/dashboard` → Model metrics (Accuracy, Precision, Recall, F1, ROC-AUC) + EDA charts

## 🧠 Models Compared (train.py)
- Logistic Regression
- Random Forest
- Gradient Boosting

Best model **ROC-AUC score** ke basis pe automatically select hota hai aur save hota hai.

## 🛠️ Customization Tips
- Naya feature add karna ho to: `clean.py` mein `NUMERIC_COLS`, `app.py` mein `FORM_FIELDS` dono update karo.
- Model tune karna ho to `train.py` ke `candidates` dict mein hyperparameters change karo ya `GridSearchCV` add karo.
- UI colors change karne ke liye `static/css/style.css` ke top pe `:root` variables edit karo.

## ⚠️ Common Issues
| Problem | Solution |
|---|---|
| `FileNotFoundError: telecom_churn.csv` | Dataset ko `data/` folder mein sahi naam se rakho |
| `Model not trained yet` on `/predict` | Pehle `clean.py` phir `train.py` run karo |
| TotalCharges error | Already handled in `clean.py` (blank strings ko 0 se fill karta hai) |
